ESPHA

Прошивка для круглого дисплея Waveshare ESP32-S3-Touch-AMOLED-1.43 (466×466). Показывает часы и данные из Home Assistant. Устанавливается прямо из браузера — ничего ставить на компьютер не нужно.

Нужен Chrome, Edge или Opera на компьютере — Web Serial не работает в Safari, Firefox и на телефоне. Страницу нужно открыть по https:// или на localhost.

Подключите плату к компьютеру кабелем USB-C и нажмите «Connect».

Версия прошивки на этой странице: __BUILD_VERSION__

Как прошить

  1. Откройте эту страницу в Chrome, Edge или Opera на компьютере.
  2. Подключите плату кабелем USB-C. Кабель должен быть с передачей данных, а не только для зарядки.
  3. Нажмите кнопку установки и выберите появившийся COM-порт (обычно USB JTAG/serial debug unit).
  4. Выберите Install ESPHA и дождитесь окончания записи (2–3 минуты). Если плата уже прошита, вместо этого будет Update ESPHA.
  5. Тут же в браузере введите имя и пароль вашей сети Wi-Fi.
  6. Откройте Home Assistant — устройство появится в Настройки → Устройства и службы как новое ESPHome-устройство. Нажмите «Настроить».

Если не предлагается обновление

ESP Web Tools показывает Update только когда версия на плате отличается от версии на этой странице. Сверьте версию выше с той, что диалог показывает под надписью «Connected to…». Если они совпадают, а вы ждёте свежую сборку — обновите страницу с Ctrl+Shift+R: браузер мог оставить в кеше старый манифест.

Если плата не появляется в списке портов

  1. Отключите кабель.
  2. Зажмите кнопку BOOT на плате и, не отпуская, подключите кабель — плата войдёт в режим загрузки.
  3. Отпустите кнопку и повторите установку.

Что на экране

Часы

Время, дата и два значения из Home Assistant. Кольцо по краю показывает, сколько прошло от суток.

Дом

Четыре плитки с любыми числовыми сущностями: температура, влажность, потребление.

Принтер

Прогресс печати Bambu Lab: кольцо, проценты, температуры сопла и стола, слой и остаток времени.

Устройство

Wi-Fi, IP, время работы и регулятор яркости AMOLED.

Страницы листаются свайпом влево-вправо или кнопкой BOOT.

Настроить свои сущности

После добавления устройства в Home Assistant откройте надстройку ESPHome Builder, найдите espha и поправьте подстановки slot1_entity…slot4_entity, подписи и часовой пояс. Затем нажмите «Install» — обновление уйдёт по воздуху. Подробности — в README проекта.
